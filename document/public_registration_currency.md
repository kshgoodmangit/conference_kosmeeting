# 사용자 사전등록 통화 및 카드 결제 기준

`PublicPreRegistrationService`를 사용하는 사용자 사전등록 화면과 `/mypage/registration`에 적용한다.

## 신규 신청

- 회원 정보의 국가가 `South Korea`이면 등록비와 유료 옵션을 KRW로 계산하고 `domestic-card` 경로를 사용한다.
- 그 외 국가는 USD로 계산하고 `international-card` 경로를 사용한다.
- 국가의 앞뒤 공백과 영문 대소문자는 무시한다. `Republic of Korea`, `Korea, Republic of`, `KR`, `KOR`, `대한민국`도 한국으로 처리한다.
- 국가가 입력되어 있으면 회원유형과 관계없이 국가를 우선한다. 예를 들어 `international` 회원도 국가가 `South Korea`이면 KRW를 적용한다.
- 과거 국내 가입 방식에서는 국가를 저장하지 않았으므로, 국가가 비어 있는 `domestic` 회원만 `South Korea`로 간주한다.
- 서버가 회원 국가와 등록비·옵션 가격을 조회하여 통화 및 금액을 결정한다. 화면에서 통화나 금액을 지정하지 않는다.

## 기존 신청

- 조회 및 결제 시 신청에 저장된 통화와 금액을 유지한다. 이후 회원 국가를 변경해도 자동 환산하거나 변경하지 않는다.
- 미결제 신청을 사용자가 직접 수정하면 저장된 통화로 현재 등록 기간의 등록비와 선택 옵션 금액을 다시 계산한다.
- 카드 결제 경로와 결제 가능 여부는 저장된 통화를 기준으로 결정한다. KRW는 국내카드, USD는 해외카드다.
- 해당 결제 경로가 설정되지 않았거나 설정 통화가 다르면 다른 경로로 자동 전환하지 않는다. PG 요청 결과의 통화와 금액도 저장된 신청과 대조한다.
- KRW와 USD 이외의 저장 통화는 오류로 처리한다.

기존 신청 데이터의 일괄 변경이나 DB 스키마 변경은 필요하지 않다. PG의 승인 검증 및 결제 결과 확정 방식은 기존 구현을 따른다.

## 검증

`PublicPreRegistrationServiceTest`에서 국가별 요금·옵션 계산, 기존 국내회원 호환, 국가 변경 후 신청 통화 유지, 카드 경로 선택, PG 통화·금액 불일치 거부를 확인한다. 컨트롤러 및 PayGate 어댑터 테스트도 함께 실행한다.
