# 행사 현황판 집계 기준

대상 화면: `/admin/dashboard/board`

## 학회 선택과 조회

- 상단의 관리 학회 선택값을 `X-Conference-Seq` 헤더로 전달하여 `GET /api/admin/dashboard/board`를 호출한다.
- 학회를 변경하면 이전 요청을 취소하고 새 학회의 데이터가 도착할 때까지 로딩 상태를 표시한다. 다른 학회의 응답을 표시하지 않는다.
- 전체 관리자 세션과 행사 현황판 라이선스가 필요하다. 학회 미선택·존재하지 않는 학회는 기본 학회로 대체하지 않는다.
- 집계 시각을 화면에 표시한다. 진입 또는 학회 선택 변경 시 조회하며, 화면의 현재 시계와 집계 시각은 구분한다.

## 지표

| 항목 | 기준 |
|---|---|
| 사전등록·결제 완료율 | 선택 학회의 `SUBMITTED` 등록 중 `PAID`, `UNPAID`, `FAILED`. 취소·환불은 제외한다. 완료율은 `PAID / 유효 등록`이다. |
| 전체 등록비·오늘 등록비 | 결제 완료 등록의 `paidAmount`, 없으면 `totalAmount`, 없으면 `feeAmount`. 통화별로 분리하고 오늘 금액은 `paidAt` 기준이다. |
| 초록 접수·분야별 구성 | 선택 학회의 `submitted`, `under_review`, `approved`, `rejected` 초록. 임시저장을 제외하고 기존 운영 대시보드의 분야별 집계를 사용한다. |
| 심사 미배정·기한 초과 | 기존 `OperationalDashboardRepository.abstractFields`의 초록별 집계 기준을 재사용한다. 배정 수만큼 초록이 중복 집계되지 않는다. |
| 후원액 | 선택 학회의 후원 신청 중 입금 완료 후원액 합계. 원화 기준이다. |
| 세금계산서 미발행 | 입금 완료 후원 신청 중 발행일이 없는 건수. |
| 국가별 참가자 | 유효 사전등록에 연결된 같은 학회 회원의 국가를 ISO 코드·국가명과 대조한다. 국가 미지정은 별도 집계하며 실제 국가 수와 지구본에서는 제외한다. |
| 함께하는 후원사 | 선택 학회에 등록된 사용 상태의 스폰서. 과거 행사도 확인할 수 있도록 현재 노출 기간으로 제한하지 않는다. |
| 오늘 신규 회원·사전등록 | 서울 시간 오늘의 `createdAt` 기준. 신규 등록 수는 이후 취소·환불된 접수도 포함한다. |
| 오늘 신규 초록 | 오늘의 `submittedAt` 기준, 값이 없으면 `createdAt`. 임시저장 제외. |

## 일정과 추이

- 행사명·개최일·장소·마감일은 선택 학회의 설정을 사용한다. 고정 시안 수치는 사용하지 않는다.
- 개최 예정·진행 중인 행사는 오늘까지 최근 7일의 일별 초록 제출·사전등록 접수 건수를 표시한다.
- 행사 종료일이 지난 학회는 행사 시작 전 마지막 7일을 표시한다. 차트 제목과 날짜 범위에 이를 명시한다.
- 차트의 사전등록은 접수일 기준이므로 취소·환불을 제외한 상단 유효 등록 수와 기준이 다르다.
- 지난 학회의 ‘오늘 처리 현황’도 실제 오늘 기준이다. 과거 접수를 오늘 발생한 것처럼 표시하지 않는다.
- 데이터 없는 날짜는 0으로 채운다. 조회 실패는 0건으로 표시하지 않고 공통 토스트와 재시도 상태를 제공한다.
