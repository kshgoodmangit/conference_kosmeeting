# 엑셀 다운로드 파일 추적

## 적용 범위

`ExcelDownloadAuditService.execute`를 거치는 관리자 계정, 회원, 초록, 사전등록 엑셀 다운로드에 자동 적용한다. 배포 후 새로 생성한 파일부터 적용되며 과거 파일에는 소급 적용되지 않는다. 일괄등록 빈 양식 등 감사 서비스를 거치지 않는 다운로드는 대상이 아니다.

## 저장 정보

기존 `excel_download_logs.seq`를 파일에 문자열로 저장한다. DB 스키마나 환경변수 추가는 필요 없다.

| 항목 | 사용자 지정 문서 속성 | `_download_info` 시트의 값 위치 |
| --- | --- | --- |
| 형식 버전 (`1`) | `ICMS.TraceVersion` | B1 |
| 다운로드 이력 번호 | `ICMS.DownloadLogId` | B2 |
| 다운로드 유형 | `ICMS.ExportType` | B3 |

시트 A열에는 각 항목의 키를 기록한다. 시트는 `veryHidden` 상태이므로 일반 숨기기 취소 목록에 나타나지 않는다. 요청자 이름, 이메일, IP, 사유는 추적정보에 추가하지 않고 기존 서버 이력에서 확인한다.

생성한 파일에 추적정보를 삽입한 다음 성공 이력을 저장한다. 기록되는 파일 크기도 삽입 후 실제 응답 파일의 크기다. 삽입이나 성공 이력 저장에 실패하면 파일 응답을 반환하지 않고 기존 실패 기록 흐름을 따른다. 성공은 서버 파일 생성 성공을 의미하며 사용자 PC 저장 완료를 보장하지 않는다.

## 사고 조사 시 확인

1. 확보한 원본은 보존하고 사본으로 확인한다.
2. Windows Excel의 `파일 → 정보 → 속성 → 고급 속성 → 사용자 지정`에서 `ICMS.DownloadLogId`를 확인한다.
3. 대체 경로: `Alt + F11`로 VBA 편집기를 열고 `_download_info` 시트를 선택한다. `F4` 속성 창의 `Visible`을 `-1 - xlSheetVisible`로 변경한 후 B2를 확인한다. 매크로 코드를 실행할 필요는 없다.
4. 관리자 엑셀 다운로드 이력 목록의 맨 왼쪽 `ID` 열에서 해당 이력 번호를 대조한다. 상세 화면 제목에도 같은 번호가 표시된다. 기존 인증된 관리자 상세 API는 `GET /api/admin/excel-download-logs/{번호}`다.
5. 다운로드 유형도 대조하고, 서버 이력의 요청자·요청 시각·IP·검색 조건·건수 등과 함께 조사한다. 두 위치의 값이 다르면 수정 가능성이 있으므로 어느 한 값을 확정적인 출처로 간주하지 않는다.

## 검증 및 한계

- 자동 테스트는 실제 XLSX를 다시 열어 두 저장 위치, 매우 숨김 상태, 기존 데이터·서식·필터·틀 고정 보존과 셀 편집 후 재저장을 확인한다. Apache POI로 검증하며 실제 Microsoft Excel 및 다른 오피스 제품의 편집 동작 전체를 보장하지 않는다.
- 셀을 수정하고 XLSX로 저장하는 경우 유지하도록 설계했다. 새 파일로 데이터만 복사, CSV 변환, 숨김 정보 제거 시에는 사라질 수 있다.
- 서명·암호화·변조 방지 기능은 포함하지 않는다. 식별번호 자체는 수정하거나 다른 파일에 복사할 수 있으므로 단독 증거로 유출자를 확정해서는 안 된다.
- 워크북을 메모리에서 열고 다시 저장하므로 기존 파일 생성에 추가 CPU·메모리를 사용한다. 대량 다운로드는 운영 데이터 규모에 맞춰 별도 부하 확인이 필요하다.
