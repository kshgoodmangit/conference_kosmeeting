# 학회회원관리

## 적용

1. 애플리케이션을 빌드·배포하고 관리자 화면을 새로고침한다.

메뉴 순서: **회원·등록관리 → 회원관리 / 학회회원관리 / 사전등록관리**.

## 명부 관리

- 홈페이지 가입회원(`members`)과 독립적인 학회회원 명부(`society_members`)다. 로그인 계정은 생성하지 않는다.
- 면허번호(필수, 50자), 이름(필수, 100자), 소속(선택, 255자), 회원구분(필수: 정회원/준회원/기타)을 관리한다.
- 면허번호는 문자열이며 앞자리 0을 보존한다. 양끝 공백만 제거하고 대소문자를 구분한다. 유일 제약으로 중복 등록 경쟁도 방지한다.
- 검색어(면허번호·이름·소속)와 회원구분을 적용한다. 전체 건수와 구분별 건수는 현재 페이지가 아닌 동일 조건의 전체 결과를 서버에서 집계하여 목록과 같은 응답에 제공한다.
- 삭제는 공통 확인 다이얼로그 이후 수행하며 명부에서 실제 삭제한다. 이미 저장된 사전등록의 구분·금액은 변경하지 않는다.

## 엑셀

- 정적 양식: `frontend/public/templates/society_member_bulk_import_template.xlsx`.
- 첫 시트 `학회회원`: 제목 1행, 안내 2행, 헤더 4행, 입력 5행 이후. `작성안내` 시트에 규칙 및 복사 가능한 예시를 제공한다.
- `.xlsx`, 최대 5MB, 데이터 최대 1,000명. 헤더는 첫 10행에서 검색한다. 빈 행은 무시한다.
- 앞자리 0이 있는 면허번호는 반드시 텍스트로 입력한다. Excel에서 이미 숫자로 변환해 잃어버린 0은 복구할 수 없다.
- 파일 내 중복 및 기존 면허번호는 건너뛴다. 기존 정보 변경은 수정 화면에서 처리한다.
- 수식·오류 셀, 필수값 누락, 길이 초과, 잘못된 회원구분은 해당 행만 실패한다. 정상 행은 각각 별도 트랜잭션으로 저장한다.
- 파싱 실패·최대 행 수 초과는 저장을 시작하기 전에 거부한다. 응답에는 총/성공/건너뜀/실패 건수와 원본 Excel 행 번호·면허번호·사유를 담는다.
- 업로드 원본 파일은 영구 보관하지 않는다. 양식은 개인 데이터가 없어 다운로드 사유 입력 대상이 아니다.

## 등록비 연결 및 사전등록

1. 학술대회 설정에서 회원구분에 적용할 등록 구분과 Early Bird/Regular, KRW/USD 금액을 설정한다.
2. 학회회원관리 → **등록비 연결**에서 정회원·준회원·기타별 등록 구분을 선택한다. 실제 금액이나 할인율은 임의로 설정하지 않았다.
3. 사전등록관리 → **사전등록 추가**에서 신청할 홈페이지 회원을 선택한다.
4. **학회회원 등급 등록비 적용**을 선택하고, 해당 신청자의 면허번호와 명부상 이름을 입력하여 확인한다.
5. 일치한 명부의 회원구분과 등록 기간·통화로 등록비가 채워진다. 기간·통화·신청 회원·확인 정보를 바꾸면 재확인이 필요하다.
6. 서버는 저장 시 명부와 금액을 재확인한다. 미등록·이름 불일치·미설정·사용 중지 구분·미설정 통화는 거부하며, 확인 이후 금액 또는 연결 구분이 바뀌면 재확인을 요청한다.

명부에 없는 사람을 `기타`로 자동 분류하지 않는다. 명부에 등록된 기타 회원만 해당 등급을 적용한다. 학회회원 적용을 선택하지 않은 관리자 접수는 기존 수동 등록 방식이다.

현재 연동 대상은 **관리자 사전등록 추가**이며 기존 접수 수정은 관리자 수동 처리다. 홈페이지 가입회원에는 면허번호·학회회원 한글 이름 필드가 없으므로 홈페이지 회원과 자동 연결하지 않는다. 관리자가 선택한 신청자와 명부의 동일인 여부를 확인한다. 향후 공개 사전등록 연동 시 인증된 신청자 신원에 연결한 뒤 `SocietyMemberService.quote`를 재사용해야 하며, 이름·면허번호만으로 공개 인증 API를 제공해서는 안 된다.

## API

모두 `/api/admin/society-members` 하위이며 기존 관리자 세션·권한 인터셉터 및 CSRF 보호를 적용한다.

| 경로 | 동작 |
|---|---|
| GET / | 검색·통계·페이지 목록 |
| POST /, PUT /{seq}, DELETE /{seq} | 등록·수정·삭제 |
| POST /import | multipart file 일괄등록 |
| GET /fee-mappings, PUT /fee-mappings | 회원구분별 등록 구분 연결 |
| POST /fee-quote | 면허번호·이름 확인 후 등급별 금액 조회 |

`POST /api/admin/pre-registrations`는 선택적으로 `societyLicenseNumber`, `societyMemberName`을 받아 서버 검증을 수행한다. 금액은 기존 사전등록의 `categorySeq/categoryCode/categoryName/feeAmount/currency/periodType`에 저장된다.

## 검증 결과

- Java 17: 학회회원 및 사전등록 관련 테스트 29개 통과. 양식 구조·실제 XLSX 형식·면허번호 앞자리 0·행 수 상한·부분 실패·중복·등급별 금액 확인·관리자 권한·CSRF를 검증했다.
- TypeScript 검사, 변경 파일 ESLint, Vite 프로덕션 빌드 통과. 시스템 npm 실행 경로 오류로 로컬 TypeScript/ESLint/Vite 실행 파일을 Node로 직접 실행했다.
- Chrome에서 모의 API로 검색 조건 적용·초기화·등록·수정·삭제 확인·일괄등록 결과·등록비 연결·사전등록 금액 자동 입력·기간 변경 재확인·저장 요청을 검증했다. 라이트/다크, 좁은 화면, 모달 Escape·포커스 복원도 확인했다.
