# 초록 편성

관리자 경로는 `/admin/abstract-program`이다. 채택 초록을 프로그램 트리의 빈 발표 시간에 드래그하여 배정하는 화면으로 통일했다. 기존 선택·버튼 방식 화면과 비교용 화면 전환은 제거했다.

## 화면 구성

- 왼쪽: 채택 초록 검색·선택·상세·페이지 이동. 기본은 미배정 초록이며 6건씩 표시한다.
- 검색 조건: 초록번호·제목·실제 발표자·소속, 승인 발표형식, 카테고리, 배정 상태. 상세 조건은 접어 두고 필요할 때 펼친다. 초기화·조회·새로고침을 제공한다.
- 오른쪽: 일자 → 룸 → 세션 → 개별 초록 발표 시간의 트리. 각 그룹을 접고 펼칠 수 있다.
- 두 제목 영역은 높이 64px, 세로 중앙 정렬로 통일한다.
- 요약 통계, 자동 선택 체크박스, 개별 시간의 별도 배정 버튼은 제공하지 않는다.
- 넓은 화면은 좌우 배치와 각 목록 스크롤, 좁은 화면은 세로 배치를 사용한다.
- 프로그램 편성표 이동 버튼, 관리자 공통 확인창·오른쪽 상단 토스트를 사용한다.

## 배정 동작

1. 채택 초록 카드를 드래그하면 배정 가능한 빈 시간을 점선으로 강조한다.
2. 개별 빈 시간에 놓으면 즉시 저장한다. 일자·룸·세션 그룹에는 드롭하지 않는다.
3. 이미 배정된 시간 또는 미사용 시간에는 배정하지 않는다. 외부 드래그 데이터로 배정을 시작하지 않는다.
4. 배정 성공 시 같은 일자·룸·세션의 다음 빈 시간을 자동 선택한다. 앞 시간으로 돌아가거나 다른 세션으로 넘어가지 않는다.
5. 초록 선택을 해제하고 현재 검색 조건을 유지한다. 미배정 목록에서 방금 배정한 초록을 제외한다.
6. 갱신 중 기존 행과 트리의 펼침 상태를 유지하며 스크롤을 강제로 이동하지 않는다.
7. 저장 중 중복 조작을 차단한다. 실패하면 선택과 입력을 유지하고 공통 오류 토스트를 표시한다. 최신 조회가 실패하면 재조회까지 배정·해제를 차단한다.

`Flash Talks`는 SESSION이며 그 아래 16:30–16:35 등의 ABSTRACT_PRESENTATION 항목에 한 편씩 배정한다. 세션 없는 시간은 세션 미지정, ALL_ROOMS 시간은 전체 룸 공통으로 묶는다.

## 데이터 반영과 해제

| 정보 | 처리 |
|---|---|
| 날짜·룸·상위 세션·시간·표시 순서 | 유지 |
| 초록 연결 | 기존 program_items.abstractSubmissionSeq 사용 |
| 제목 | 채택 초록 제목 |
| 발표자 | authors.isPresentingAuthor인 저자, institutionNo로 연결한 소속, 해당 국가 |
| 기획자·좌장·부제목·비고·행 스타일·사용 여부 | 유지 |
| 원본 제목·발표자 | program_abstract_snapshots에 배정 직전 값 보관 |

발표자를 주저자·회원 이름으로 임의 대체하지 않는다. 제목 500자, 발표자 이름·소속 각각 255자, 발표자 표시 내용 합계 500자를 넘거나 발표자·소속 정보가 없으면 서버에서 배정을 거부한다.

해제는 공통 확인창을 사용한다. 배정 직후 제목·발표자가 그대로면 원본으로 복원한다. 복원 정보가 없는 기존 배정 또는 배정 후 수동 수정된 항목은 현재 제목·발표자를 유지하고 연결만 해제한다. 확인 중 다른 관리자가 내용을 변경하면 복원을 거부하고 재조회를 안내한다. 초록·프로그램 시간 항목 자체는 삭제하지 않는다.

교체는 해제 후 재배정한다. 초록 원문 수정 사항을 기존 프로그램에 자동 덮어쓰지 않는다.

## 서버 검증과 API

- 후보는 status=approved만 제공한다.
- 배정 대상은 사용 중인 ABSTRACT_PRESENTATION이며 일자·룸·일자별 룸 배정·상위 세션도 사용 중이어야 한다. 상위 세션의 일자·룸·시간 범위를 검증한다.
- program_items 전체에서 같은 초록의 중복 연결을 막는다. 미사용 프로그램의 연결도 해제 후 다시 배정해야 한다.
- 초록·프로그램 행 잠금과 트랜잭션으로 동시 배정을 제어한다. 일반 프로그램 저장 API에도 중복 검증을 적용하며 연결 제거·교체는 초록 편성에서 처리한다.
- 채택 취소, 배정 대상 미사용, 기존 중복 연결은 확인 필요로 표시한다. 프로그램 제목에서 발표형식 적합성을 추정하지 않는다.
- 기존 관리자 세션 인터셉터와 CSRF 처리를 따른다.

| 메서드 | 경로 | 내용 |
|---|---|---|
| GET | /api/admin/abstract-program | 프로그램, 연결 상태, 검색된 초록·페이지·필터 항목 |
| POST | /api/admin/abstract-program/items/{seq}/assignment | abstractSubmissionSeq 배정 |
| DELETE | /api/admin/abstract-program/items/{seq}/assignment | 예상 abstractSubmissionSeq와 restoreOriginal 여부로 해제 |
| GET | /api/admin/abstracts/{seq} | 기존 초록 상세 조회 |

## 검증

TypeScript 검사, 변경 파일 ESLint, 시간 선택·트리 구성 테스트를 실행한다. 초기 배정 기능은 Java 서비스 테스트로 채택 여부·중복 거부·실제 발표자 반영·시간 유지·해제 복원·수동 변경 보호·페이지 보정을 검증했다. 실제 브라우저에서는 정식 경로의 드래그 화면과 기존 배정 데이터 표시를 확인하며, 검증을 위해 실제 배정 데이터를 수정하지 않는다.
