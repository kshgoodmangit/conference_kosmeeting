# 학회별 등록 옵션 설정

## 사용 위치

학술대회 설정 → 학회 목록 → 수정 → **등록 옵션 설정** 탭.
새 학회는 기본 설정·등록비 저장 후 다시 열면 옵션을 추가할 수 있다.
옵션 저장은 기존 학회·등록비 저장과 별도로 즉시 처리된다.

## 제공 기능

- 학회별 옵션 추가·수정·사용 중지, 옵션명 검색·사용 여부 필터·초기화·페이지 이동.
- 현재 검색 조건 전체의 옵션 수·사용 수·미사용 수를 서버에서 집계.
- 옵션명·설명·KRW 및 USD 가격·신청 시작과 마감·변경 및 취소 마감·정원·1인당 최대 수량·표시 순서.
- 가격 공란은 해당 통화 미제공, 0은 무료. 적어도 한 통화 가격을 입력해야 한다.
- 정원 공란은 무제한, 0은 정원 없음. 날짜는 한국 시간 기준이다.
- 정렬은 표시 순서, 같은 순서는 생성 ID 기준이다.
- 서버의 학회 소속 검사와 versionNo 기반 동시 수정 충돌 방지.
- 옵션 이력 보존을 위한 사용 여부 관리. 물리 삭제 API는 제공하지 않는다.

API는 `/api/admin/congress-settings/{congressSeq}/registration-options`의 GET·POST,
동일 경로 `/{seq}`의 PUT이다. 기존 관리자 세션·IP·CSRF 통제를 따른다.

## 범위

현재는 카탈로그 설정 기능이다. 실제 신청 수량 집계·정원 차감·신청 당시 가격 스냅샷·무료 대상자 혜택 연결·결제·환불은 포함하지 않는다.
참가자 신청을 연결할 때는 `registration_paid_options_design.md`의 스냅샷 및 정원 동시성 규칙을 적용해야 한다.
현재 설정 가격 변경을 과거 신청 가격에 직접 반영하는 구조로 확장하지 않는다.

## 검증

RegistrationOptionServiceTest에서 무료와 미제공 구분, 위조 ID 무시, 가격 범위·소수 자릿수,
수량·기간 검증, 다른 학회의 옵션 수정 차단, 버전 충돌, 목록·통계 필터 일치를 검증한다.
Java 17 전용 실행기 테스트 및 프론트엔드 TypeScript·변경 파일 ESLint를 수행했다.
운영 DB 적용과 실제 브라우저 저장 검수는 별도다.
