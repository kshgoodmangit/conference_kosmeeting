# 관리자 사전등록 결제 상태 수정

기존 사전등록의 수정 모달에서 결제 대기(UNPAID), 결제 완료(PAID), 환불(REFUNDED), 결제 실패(FAILED)를 선택할 수 있다. 신규 등록은 기존대로 UNPAID로 생성한다.

관리자 수정 API가 전달받은 결제 상태를 검증하고 등록 정보·옵션 변경과 같은 트랜잭션으로 저장한다. 상태 필드를 생략하거나 기존 상태와 같으면 결제 기록을 변경하지 않는다. 수정·결제 취소·삭제는 해당 사전등록 행을 잠근 후 처리한다.

PAID로 변경할 때 기존 paidAmount가 없으면 서버에서 계산된 totalAmount, 기존 paidAt이 없으면 현재 저장 시각을 기록한다. 이미 존재하는 결제 금액·일시·수단·거래번호는 유지한다. 다른 상태로 변경하더라도 기존 결제 기록을 지우지 않으며, 결제 기록이 있는 내역의 금액·통화 변경 제한은 유지한다.

이 기능은 관리자 내역 정정이며 PG 승인·취소·환불을 실행하지 않는다. 모달에 이를 안내한다. 결제 합계는 현재 PAID 상태의 내역만 원화·달러로 구분하여 집계하고, 저장 성공 후 목록과 함께 다시 조회한다.

기존 컬럼을 사용하므로 DB 구조 변경은 필요 없다.
