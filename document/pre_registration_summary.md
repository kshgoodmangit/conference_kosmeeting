# 사전등록관리 요약 통계

목록 조회의 검색어, 등록 구분, 등록 기간, 신청 상태, 결제 상태, 신청일 조건에 해당하는 전체 결과를 서버에서 집계한다. 현재 페이지로 제한하지 않는다.

결제 합계는 결제 상태가 PAID인 내역을 KRW와 USD로 각각 합산한다. 실제 결제 금액(paidAmount)을 우선 사용하고, 값이 없으면 총 신청금액(totalAmount), 등록비(feeAmount) 순서로 사용한다. 서로 다른 통화를 합산하거나 환산하지 않는다.

목록 응답의 totalPaidKrwAmount와 totalPaidUsdAmount를 결제 합계 카드에 함께 표시한다. 로딩은 집계 중, 조회 실패는 대시, 정상 조회 결과가 없으면 각 통화 0으로 표시한다.
