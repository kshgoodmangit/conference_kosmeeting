# 초록 접수 내역 요약통계

`/admin/abstracts` 목록 API 응답의 `summary`로 집계 결과를 반환한다.
학회, 검색어, 발표형식, 최종 발표형식, 분류, 상태는 목록 건수 조회와 동일한 SQL 조건을 공유한다. 페이지 크기와 무관하게 검색 결과 전체의 초록 수를 집계한다.

| 지표 | 집계 기준 |
|---|---|
| 검색 결과 | 검색 조건에 해당하는 전체 초록. 임시저장 포함 |
| 심사자 미배정 | 제출완료·심사중 상태이며 활성 배정이 없는 초록 |
| 심사 미완료 | 제출완료·심사중 상태이며 활성 배정이 있고, 완료되지 않은 배정 또는 제출된 평가가 없는 배정이 남은 초록 |
| 최종 결정 대기 | 제출완료·심사중 상태이며 활성 배정이 1개 이상이고, 모든 활성 배정이 완료 상태이면서 각각 제출된 평가가 존재하는 초록 |
| 채택 초록수 | 검색 조건에 해당하며 최종 상태가 승인(`approved`)인 초록. 강제 승인 포함, 심사자 배정·평가 완료 여부와 무관 |

활성 배정 상태는 `assigned`, `accepted`, `in_review`, `completed`이다. 취소·거절 배정은 제외한다.
완료 평가는 배정 상태 `completed`와 해당 배정의 평가 상태 `submitted`를 모두 충족해야 한다.
임시저장·승인·반려 초록은 세 업무 대기 지표에서 제외한다. 강제 승인·반려도 최종 결정된 건이므로 제외한다.
각 업무 지표는 초록 수이며 심사자 수가 아니다. 임시저장·반려 초록 등은 업무 지표에 포함되지 않으므로 검색 결과 전체와 네 업무 지표의 합계는 일치하지 않을 수 있다.

목록과 함께 검색·등록·수정·배정·최종 결정 후 갱신한다. 로딩 중에는 `집계 중...`, 조회 실패나 통계 미수신 시에는 `-`로 표시한다.
구두·포스터 대상 화면은 이번 변경 대상에 포함하지 않는다. DB 스키마 변경은 필요 없다.
