# 엑셀 일괄등록 양식 제작 가이드

새로운 엑셀 일괄등록·일괄배정 양식은 `frontend/public/templates/admin_account_bulk_import_template.xlsx`의 문서 구조와 시각 스타일을 기준으로 만듭니다.

## 필수 문서 구조

1. 첫 번째 시트는 실제 업로드 데이터를 입력하는 시트입니다.
   - 1행: 진한 남색 배경의 양식 제목
   - 2행: 연한 파란색 배경의 짧은 입력 안내
   - 3행: 여백용 빈 행
   - 4행: 파란색 배경과 흰색 글자의 필드 헤더
   - 5행 이후: 사용자가 입력할 빈 행
2. 두 번째 시트 이름은 `작성안내`로 하고 다음 내용을 포함합니다.
   - 양식 제목
   - `구분 / 작성 규칙` 형태의 규칙 표
   - 필수값, 허용값, 중복 및 부분 실패 처리 기준
   - 첫 번째 시트에 복사할 수 있는 작성 예시
3. 예시 데이터는 실제 업로드 시트에 미리 넣지 않고 `작성안내` 시트에만 둡니다. 샘플 데이터가 실수로 등록되는 것을 방지하기 위한 규칙입니다.

## 필드 및 사용성 규칙

- 필수 헤더에는 `*`를 붙입니다.
- 내부 PK 대신 관리자가 화면에서 확인할 수 있는 업무 식별자를 사용합니다.
- 아이디 필드는 실제 저장 형식을 따릅니다. `admin_accounts.email`처럼 컬럼명이 email이어도 값이 `admin`, `reviewer1` 형식이면 이메일 예시나 이메일 형식 검증을 넣지 않습니다.
- 식별자 셀은 Excel에서 자동 변환되지 않도록 텍스트 형식으로 지정합니다.
- 입력 헤더에는 자동 필터를 적용하고, 입력 시 헤더가 보이도록 4행까지 고정합니다.
- 컬럼 너비와 행 높이는 긴 헤더와 안내문이 잘리지 않도록 지정하고, 제목·안내·헤더 색상은 관리자 계정 일괄등록 양식과 통일합니다.
- 카테고리처럼 허용값이 정해진 필드는 가능한 경우 드롭다운 데이터 검증을 제공합니다.

## 구현 및 검증 규칙

- 내용이 고정된 일괄등록 양식은 `frontend/public/templates/`에 `.xlsx` 파일로 두고 프론트엔드에서 `/templates/파일명.xlsx` 링크로 바로 다운로드합니다. 다운로드할 때마다 서버에서 같은 엑셀을 새로 생성하는 API를 만들지 않습니다.
- 행사 정보나 사용자별 데이터처럼 다운로드 시점에 내용이 달라지는 경우에만 서버에서 엑셀을 동적으로 생성합니다.
- 업로드 파서는 제목과 안내 행을 고려하여 첫 10행 안에서 헤더를 검색해야 합니다.
- 양식 다운로드와 업로드가 사용하는 헤더명은 반드시 동일해야 합니다.
- 최대 행 수, 파일 확장자, 파일 크기 제한을 화면 안내와 서버 검증에 동일하게 적용합니다.
- 일부 행만 실패할 수 있는 기능은 성공·건너뜀·실패 건수와 행 번호별 사유를 반환합니다.
- 양식 변경 후에는 생성된 `.xlsx`를 직접 열거나 렌더링하여 두 시트의 제목, 안내, 헤더, 컬럼 너비, 줄바꿈, 예시가 잘리지 않는지 확인합니다.
- 테스트에서는 시트명, 헤더 행 위치, 필수 헤더, 예시 값 및 이메일 형식이 아닌 로그인 아이디 예시를 검증합니다.
