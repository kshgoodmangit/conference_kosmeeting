# 프로그램 관리 검색

- `/api/admin/program`의 `keyword`, `itemType`, `enabled` 조건을 AND로 적용한다.
- 검색은 현재 학회의 모든 행사 일자를 대상으로 하며, 키워드는 프로그램명·부제목·비고·기존 담당자 표시 문구와 사용 중인 담당자의 이름·소속에 대해 대소문자 구분 없이 부분 일치한다.
- 서버가 동일 조건으로 검색 대상 ID와 전체 결과·사용·미사용 건수를 함께 반환한다. 일자 및 룸 탭은 검색된 결과의 표시 범위를 좁히며 상단 통계는 모든 일자의 검색 결과 기준이다.
- 편집에 필요한 세션 관계, 하위 발표 삭제 확인, 담당자 및 룸 정보는 원본 목록을 유지한다.
- 조회 또는 Enter, 프로그램 유형·사용 여부 변경 시 현재 입력 조건을 함께 적용하고 첫 검색 결과가 있는 일자로 이동한다. 초기화는 모든 검색 조건과 룸 선택을 해제한다.
- 등록·수정·삭제 후 적용된 조건으로 목록과 통계를 다시 조회한다.
